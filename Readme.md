# Ankit — AI/ML and computer-vision builder

I build practical tools and experiments that turn messy information into useful, verifiable outputs. My work sits at the intersection of OCR, document intelligence, visual AI, and product-focused software.

## What I build

- OCR and document-intelligence workflows for extracting structure from noisy documents.
- Data products that make technical comparisons easier to explore and understand.
- AI-assisted tools that turn visual content into structured, reusable notes.

## Selected work

- [APU Matrix](https://github.com/PiKa919/APU-Matrix) — a phone performance-versus-price comparison dashboard.
- [unscroll](https://github.com/PiKa919/unscroll) — a visual document extraction tool for turning carousel content into Markdown.
- [paddle-ui](https://github.com/PiKa919/paddle-ui) — a PaddleOCR-based OCR and document-parsing UI with layout and structured output.
