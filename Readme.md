# 💫 About Me:
I'm Ankit Das, an AI systems engineer building document intelligence, multimodal applications and reliable inference services.<br><br>At IDVerse, I worked on production document-AI pipelines across 10+ document types, combining OCR, VLM/LLM inference, structured extraction and Python backends. I enjoy the engineering challenges around models: memory limits, concurrency, deployment, evaluation and failure recovery.<br><br>My projects include **ForgeSight**, an inference and review workbench; **MP-KG-RAG**, an evidence-grounded retrieval and evaluation pipeline; and **UnScroll**, a multimodal extraction application.<br><br>I work mainly with Python, TypeScript, FastAPI, React, PyTorch, ONNX Runtime and SQL. Currently exploring AI infrastructure, agent reliability and open-source contributions.<br><br>Open to AI engineering, founding engineer and freelance opportunities.<br>
